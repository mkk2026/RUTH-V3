## 2025-06-14 - Preventing App-Wide Re-renders from High-Frequency Audio Data
**Learning:** Storing high-frequency data (like audio analyzer arrays or frequent socket events) in the root React component (`App.jsx`) state causes severe cascading app-wide re-renders. Every new frame of audio data forces the entire app tree to render. In addition, using `requestAnimationFrame` inside functional components (`TopAudioBar`) without saving the animation ID and calling `cancelAnimationFrame` in the `useEffect` cleanup creates severe memory and CPU leaks.
**Action:** Always pass high-frequency data down as `useRef` props to visual components. Let the child components read from the ref within their own internal rendering loops (`requestAnimationFrame`). Always remember to call `cancelAnimationFrame(animationId)` in cleanup functions for any `requestAnimationFrame` loops created in `useEffect`.
