## 2026-06-09 - Refactored React Component Animation Loops
**Learning:** Storing high-frequency real-time event data (e.g., audio arrays, fps) in standard React components causes severe cascading top-down UI rendering and performance issues. This occurs because the parent `App.jsx` component triggers re-renders 60+ times per second as `useState` hooks are hit repeatedly from `requestAnimationFrame` hooks and rapid socket inputs.
**Action:** Pass reactive values using `useRef` when updating visualization states instead of direct `useState` tracking, allowing specific leaf components to manage their visual changes on their own loops. Update internal canvas rendering loops using `requestAnimationFrame()` directly on DOM ref outputs, preventing the React event lifecycle from being forced to diff over unneeded states.
