## 2024-05-24 - React Audio Visualizer Re-Renders
**Learning:** High-frequency data streams (like raw microphone `analyser` node byte arrays and websocket audio data) stored in a parent React component's `useState` causes severe cascading UI re-renders, dropping the framerate significantly. The `App.jsx` component was re-rendering 60+ times per second just to pass the `aiAudioData` and `micAudioData` down to visualizer canvases.
**Action:** Always decouple animation data from React's reactive state when building 60 FPS visuals. Store high-frequency data arrays in a `useRef` and pass the `ref` itself down to the child components. The child components should then read directly from `ref.current` within their own independent `requestAnimationFrame` loops, updating only the canvas without triggering React render lifecycles.
