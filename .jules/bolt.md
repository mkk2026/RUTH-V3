## 2025-03-05 - Avoid Root Component State for High-Frequency Data
**Learning:** Storing high-frequency real-time data, such as audio analyzer arrays (`aiAudioData`, `micAudioData`) received from WebSockets or Web Audio API, in the root React component's (`App.jsx`) state causes severe cascading app-wide re-renders. This results in significant performance degradation as the entire application tree re-renders dozens of times per second.
**Action:** Instead of `useState`, use `useRef` to store rapidly changing data in the parent component. Pass the ref to child components (like `Visualizer` or `TopAudioBar`) and let them read the data directly within their own internal `requestAnimationFrame` loops. Alternatively, pass the source object (e.g., `analyser` node) down so children can handle their own update loops autonomously. Always ensure to store the animation ID and call `cancelAnimationFrame(animId)` in the cleanup function to prevent memory leaks.
