## 2026-06-05 - App.jsx High Frequency State Bottleneck
**Learning:** The root React component (`App.jsx`) was storing extremely high-frequency data (`aiAudioData` from socket events and `micAudioData` from a `requestAnimationFrame` loop reading a Web Audio analyser) in standard `useState`. This caused the massive 1800+ line component, and all of its deeply nested children, to completely re-render up to 60 times a second. Moving this data to `useRef` and passing references down to specific leaf components drastically reduces main thread blocking.
**Action:** Always verify if continuous fast-changing streams (sockets, `requestAnimationFrame`, Web Audio) are tied to `useState` high up in the component tree. Pass down data source references (e.g. `analyserRef`) instead and have leaf nodes execute localized loops.
